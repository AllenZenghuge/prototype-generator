4. Errors and fixes:
   - **SSL certificate error with Python 3.8 urllib**: Fixed by using `certifi.where()` with `ssl.create_default_context()`
   - **Images unsupported by Read tool**: Used Qwen3-VL-Plus API via Python + urllib + base64 for screenshot analysis
   - **uvicorn version 0.34.0 doesn't exist**: Used 0.33.0 instead (closest available)
   - **Python 3.8 type annotation compatibility**: Changed `list[...]` → `typing.List[...]`, `dict | None` → `Optional[dict]`
   - **APIClient.swift:25 — stray `}` after edit**: Removed extra closing brace that broke class structure
   - **GradientArrowButton opacity inverted**: Changed `.opacity(isLoading ? 0 : 1)` → `.opacity(isLoading ? 1 : 0)`
   - **Xcode 26.3: no Minimum Deployment in wizard**: Manually set IPHONEOS_DEPLOYMENT_TARGET in pbxproj from 26.2 → 17.0
   - **Xcode 26.3: no Info.plist file**: Project uses GENERATE_INFOPLIST_FILE=YES, added INFOPLIST_KEY_ entries to build settings
   - **Xcode 26.3: xcodebuild test hangs indefinitely**: Simulator CLI unstable on beta, marked XCTest as pending
   - **"无法解析推文页面结构" on real tweet**: X changed structure, __NEXT_DATA__ no longer embedded. Switched to vxtwitter API
   - **Backend httpx not using Mac proxy**: Added proxy config, then per user feedback changed from hardcoded to env var
   - **`pkill` and `networksetup` commands denied by auto mode**: Used `lsof -ti:8000 | xargs kill` instead
   - **Chinese path encoding in shell commands**: Used full absolute paths via variable expansion
