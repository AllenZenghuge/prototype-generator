2. Key Technical Concepts:
   - SwiftUI iOS 17+ with @Observable macro (MVVM)
   - SwiftData @Model for persistence (DownloadItem) — thread safety issues identified as root cause of BUG-003
   - "删旧建新" strategy for re-download: delete old DownloadItem + insert new one (avoids in-place mutation problems)
   - Python backend with FastAPI + httpx + Pydantic, vxtwitter API for X parsing
   - Glassmorphism with backdrop-filter, saturate(), inset highlights
   - Visual companion server (Superpowers/brainstorming) for mockup iteration
   - ui-ux-pro-max design system generation + frontend-design critique workflow
   - Qwen3-VL-Plus for image analysis via dashscope API (with certifi SSL context)
   - NotificationCenter for download status updates in iOS
   - Floating capsule tab bar pattern (240px wide, 28px border-radius, centered with bottom margin)
