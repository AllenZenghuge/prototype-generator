## 1. 设计方向

| 维度 | 决策 |
|------|------|
| 风格 | 毛玻璃主导（Glassmorphism），Apple 原生质感 |

## 2. 设计系统

### 色彩

| Token | 浅色 | 深色 | 用途 |
|-------|------|------|------|
| 背景 | 多色冷紫渐变 `#d8d4f0→#f0edfa→#e4e0f5` | 多色深紫渐变 `#020203→#080610→#0a0a12→#06050d` | L0 底层 |
| 光斑 | 3 个冷紫光斑，opacity 22-35%，blur 70-90px | 3 个冷紫光斑，opacity 14-22%，blur 60-80px | L1 氛围 |
| L3 输入卡片 | `rgba(255,255,255,0.45)` + blur 50 + saturate(160%) | `rgba(255,255,255,0.10)` + blur 50 + saturate(150%) | 输入区 |
| L2 卡片 | `rgba(255,255,255,0.35)` + blur 45 + saturate(150%) | `rgba(255,255,255,0.07)` + blur 45 + saturate(140%) | 列表/结果 |
| 强调色 | `#6C5CE7` | `#8B7CF6` | CTA / 选中 |
| 成功 | `#34C759` | `#30D158` | 下载完成 |
| 警告 | `#FF9F0A` | `#FFD60A` | 续费/提醒 |

### 材质层级

```
L0  多色冷紫渐变底 + 3 光斑（浅色 opacity 22-35% / 深色 14-22%）
L1  光斑 radial-gradient + gaussian blur 70-90px（浅色）/ 60-80px（深色）
L2  35% white + blur 45 + saturate(150%) + 1px/50% white 边框 + inset 高光线（浅色）
    7% white + blur 45 + saturate(140%) + 1px/10% white 边框（深色）
L3  45% white + blur 50 + saturate(160%) + 1px/60% white 边框 + inset 0 1px 0 white 80% + 阴影（浅色）
    10% white + blur 50 + saturate(150%) + 1px/12% white 边框 + inset 0 1px 0 white 5% + 阴影（深色）
```

> 以上为增强版参数（来源：mockup 12/13/14）。saturate 是 iOS 毛玻璃的关键——让透过玻璃看到的背景色彩更鲜艳，而非纯灰半透明。

## 3. 界面结构

### 底部 3 Tab

```
提取    下载列表    我的
```

### 提取页面
- 毛玻璃输入卡片（L3，视觉焦点）
- 「显影」CTA 按钮
- 解析结果：三栏 Tab（视频/图片/文案）+ 每项复选框
- 仅保存当前 tab 勾选项

### 下载列表
- 毛玻璃卡片列表项，4 种状态：
  | 状态 | 指示器 | 操作 |
  |------|--------|------|
  | 下载中 | 紫色进度条 | 等待 |
  | 已完成 | 绿色圆点 | 重新下载 / 复制链接 / 删除 |
  | 失败 | 红色圆点 + 原因 | 重新下载 / 复制链接 / 删除 |
  | 文案 | 绿色圆点 | 重新下载 / 复制链接 / 删除 |
- 空状态：📭 + "没有任何下载记录" + 引导文字
- 重新下载逻辑：重新解析 → 删旧建新（所有类型一致）

### 我的
- 顶部：右上角 ⚙ 设置入口（毛玻璃圆形按钮）
- 用户信息区：头像 + 手机号 + "升级会员解锁全部特权"
- 续费失败横幅：⚠ + 黄色半透明底 + 毛玻璃
- 会员卡片：👑 + 紫蓝渐变 (#6C5CE7→#A78BFA) + 发光阴影
- 功能菜单（毛玻璃卡片，单行分隔）：
  1. 联系客服 — 副标题"建议和问题反馈"
  2. 分享好友
  3. 分享送会员
  4. 好评送会员
  5. 我的礼券
  6. 清除缓存 — 显示当前大小
  7. 版本信息 — 显示版本号
- 设置页面（从头像行 ⚙ 进入，独立 push 页面）：
  - 导航：‹ 返回 + "设置" 标题
  - 账户信息卡片：用户 ID / 手机号 / VIP 到期时间（标签+值，只读）
  - 功能卡片：兑换 VIP（链接）、自动识别剪贴板链接（Toggle 开关 + 说明文字）
  - 法律卡片：用户协议、隐私政策（链接）
  - 登出：居中，独立卡片。点击 → 毛玻璃弹窗确认（👋 "确认登出？"）→ loading → 成功 → 跳转登录页。数据保留。
  - 危险操作：注销账号（红色居中，红色边框卡片）。点击 → 二次确认弹窗（⚠ "此操作不可撤销。所有下载记录、会员权益将被永久删除。"）→ loading → 清空提示 → 跳转登录页

## 6. 深色模式完整规范（v9）

### 色彩 Token

| Token | 浅色 | 深色 | 说明 |
|-------|------|------|------|
| 背景底 | #F2F2F7 | **#020203 → #06050d (gradient)** | 深色用多层渐变避免纯黑 |
| 氛围光斑 | rgba(108,92,231,0.18) | **rgba(108,92,231,0.06–0.12)** | 深色光斑减半 |
| L3 输入卡片 | **rgba(255,255,255,0.45) + blur 50 + saturate(160%)** | **rgba(255,255,255,0.10) + blur 50 + saturate(150%)** | 增强后 |
| L3 边框 | **rgba(255,255,255,0.60) 1px** | **rgba(255,255,255,0.12) 1px** | |
| L3 内发光 | **inset 0 1px 0 white 80%** | **inset 0 1px 0 white 4%** | |
| L2 结果/列表卡片 | **rgba(255,255,255,0.35) + blur 45 + saturate(150%)** | **rgba(255,255,255,0.07) + blur 45 + saturate(140%)** | 增强后 |
| L2 边框 | **rgba(255,255,255,0.50) 1px** | **rgba(255,255,255,0.10) 1px** | |
| 下载中卡片 | 38% white + blur 45 + saturate(150%) | 8% white + blur 45 + saturate(150%) | 略高于普通卡片 |
| 强调色 | #6C5CE7 | **#8B7CF6** | 深色下提亮保证对比度 |
| 主文字 | #1C1C1E | **#FFFFFF / #EDEDEF** | 深色全文白 |
| 次文字 | #8E8E93 | **rgba(255,255,255,0.35)** | 深色用透明度分层 |
| Tab Bar 背景 | rgba(249,249,249,0.85) | **rgba(24,24,28,0.85)** | |
| Tab Bar 高亮 | rgba(0,0,0,0.06) | **rgba(255,255,255,0.08)** | 反相 |
| 成功绿 | #34C759 | **#30D158** | iOS 系统适配 |
| 警告橙 | #FF9F0A | **#FFD60A** | iOS 系统适配 |

### 材质层级

| 层级 | 浅色 | 深色 |
|------|------|------|
| L0 基础底 | systemGray6 + 光斑 | linear-gradient(#020203→#06050d) + 光斑（减半） |
| L1 光斑 | opacity 12-18%, blur 60-80px | opacity 6-12%, blur 60px |
| L2 卡片 | 35% white + blur 45 + saturate(150%) | 7% white + blur 45 + saturate(140%) |
| L3 输入 | 45% white + blur 50 + saturate(160%) | 10% white + blur 50 + saturate(150%) |
| L4 浮层 | .thinMaterial + shadow | 8-10% white + blur 50 + dark shadow |

### 深色模式特殊规则

- **不用纯黑** — 背景用多层深色渐变，避免 OLED smear
- **光斑减半** — 深色背景下光斑更显眼，opacity 降低 30-50%
- **强调色提亮** — #6C5CE7 → #8B7CF6，保证深底对比度 ≥4.5:1
- **毛玻璃用极低白度** — 不是"深灰半透明"，而是"极少量白色 + blur"
- **文字用透明度分层** — 100%/50%/35%/25%，而非多个灰色 hex
- **阴影更深更广** — 0 8px 40px, opacity 0.4-0.5
