## 决策时间线

### 17. 设计风格方向

- **决策**: 毛玻璃主导（方案 B），拒绝原生 Apple（方案 A）和内容至上（方案 C）
- **原因**: C 端年轻人偏好现代感，毛玻璃 + 冷紫渐变在 App Store 中有差异化，「暗房」主题过于小众
- **参考**: iOS 原生毛玻璃（.regularMaterial / .ultraThinMaterial），但用自定义参数替代系统材质以获得更明显的玻璃质感

### 18. 深浅模式

- **决策**: 跟随系统自动切换（浅色+深色双模），不再强制深色
- **原因**: v1.1 强制 `.preferredColorScheme(.dark)` 在白天使用体验差；双模是现代 App 标配
- **深色模式特殊规则**:
  - 不用纯黑，用多层深色渐变 `#020203→#06050d` 避免 OLED smear
  - 光斑 opacity 减半（22-35% → 14-22%），深色背景下光斑更显眼
  - 强调色提亮 #6C5CE7 → #8B7CF6，保证对比度 ≥4.5:1
  - 文字用透明度分层（100%/50%/35%/25%），而非多个灰色 hex

### 19. 配色方案

- **决策**: 冷紫 #6C5CE7（浅色）/ #8B7CF6（深色）为唯一强调色
- **原因**: ui-ux-pro-max 推荐粉蓝方向，frontend-design 批判后改用冷紫——更有品质感，不与竞品撞色，且深色模式下提亮后对比度达标
- **色彩体系**（增强版）:

| Token | 浅色 | 深色 |
|-------|------|------|
| 背景 | 多色冷紫渐变 `#d8d4f0→#f0edfa→#e4e0f5` | 多色深紫渐变 `#020203→#080610→#0a0a12→#06050d` |
| 光斑 | 3 个冷紫光斑，opacity 22-35%，blur 70-90px | 3 个冷紫光斑，opacity 14-22%，blur 60-80px |
| 强调色 | #6C5CE7 | #8B7CF6 |
| 成功 | #34C759 | #30D158 |
| 警告 | #FF9F0A | #FFD60A |

### 20. 字体方案

- **决策**: SF Pro + 苹方（系统原生）
- **原因**: ui-ux-pro-max 推荐 Noto Sans Hebrew，frontend-design 批判——中英文混排场景下 SF Pro + 苹方是最佳组合，不引入外部字体减少包体积

### 21. 导航结构

- **决策**: 3 Tab 悬浮胶囊（提取 · 下载列表 · 我的），替代 v1.1 的单页 NavigationStack
- **原因**: 竞品「大神水印」有「我的」入口，用户需要设置、会员等功能入口；悬浮胶囊比传统 Tab Bar 更有设计感
- **规格**: 240px 宽，28px border-radius，底部 6-8px 留空，水平居中
- **选中态**: 底部半透明高亮胶囊（22px border-radius），浅色 rgba(0,0,0,0.06)、深色 rgba(255,255,255,0.08-0.10)
- **容器**: 浅色 rgba(249,249,249,0.85) + blur 50，深色 rgba(24,24,28,0.85) + blur 50

### 22. 毛玻璃强度

- **决策**: 采用增强版参数（mockup 12/13），拒绝初版较淡的玻璃效果
- **原因**: 初版透明度太低，玻璃质感不明显；增强后 saturate + inset 高光线让层次感显著提升，更接近 iOS 原生毛玻璃的「染色」效果

| 层级 | 浅色（增强后） | 深色（增强后） |
|------|-------------|-------------|
| L3 输入卡片 | 45% white + blur 50 + saturate(160%) + 1px/60% white 边框 + inset 0 1px 0 white 80% | 10% white + blur 50 + saturate(150%) + 1px/12% white 边框 + inset 0 1px 0 white 5% |
| L3 阴影 | 0 4px 24px rgba(0,0,0,0.06) | 0 4px 24px rgba(0,0,0,0.3) |
| L2 卡片 | 35% white + blur 45 + saturate(150%) + 1px/50% white 边框 | 7% white + blur 45 + saturate(140%) + 1px/10% white 边框 |
| 下载中卡片 | 38% white + blur 45 + saturate(150%) | 8% white + blur 45 + saturate(150%) |

### 23. 「我的」页面布局

- **决策**: C3 分离式布局（v4 定稿，mockup 20），经历三轮探索：
  1. **方案对比**（mockup 16）：A 圆球并列 / B 悬浮会员岛 / C 极简行内 → 选 C 方向
  2. **差异化最大化**（mockup 17）：C1 仪表盘 / C2 光环进度 / C3 异形层叠 → 选 C3
  3. **C3 迭代**（mockup 18-20）：v2 交叠→v3 分离→v4 ⚙并入头像行，会员计划加大
- **最终布局（从上到下）**:
  1. 会员计划（置顶，深色底 `#13102a→#0d0a1e` + 光斑 + 👑 + PRO 标签）
  2. 头像行（毛玻璃圆形头像 + 手机号 + PRO 徽章 + ⚙ 设置按钮同行右端）
  3. 续费失败（紫蓝渐变 `#6C5CE7→#8B7CF6→#A78BFA` 独立卡片）
  4. 菜单列表（毛玻璃卡片：联系客服/分享好友/分享送会员/好评送会员/我的礼券/清除缓存/版本信息）
- **参考**: 竞品「大神水印」— 横幅+卡片结构

### 24. 设置页面

- **决策**: 从「我的」头像行 ⚙ 进入，独立 push 页面，包含登出和注销
- **页面结构**:
  - 账户信息卡片（L2 毛玻璃）：用户 ID / 手机号 / VIP 到期时间（只读）
  - 功能卡片：兑换 VIP / 自动识别剪贴板链接（Toggle 开关）
  - 法律卡片：用户协议 / 隐私政策
  - 登出：居中独立卡片，紫色文字
  - 注销：居中独立卡片，红色文字 + 红色边框（危险操作视觉分离）

### 25. 登出 vs 注销

- **决策**: 分离设计，视觉差异明显，防止误操作

| 维度 | 登出 | 注销 |
|------|------|------|
| 数据 | 保留本地 | 清除全部 |
| 可逆 | 重新登录即可 | 不可撤销 |
| 弹窗按钮 | 紫色 #8B7CF6 | 红色 #FF453A |
| 弹窗边框 | 普通白色边框 | 红色边框 rgba(255,69,58,0.20) |
| 背景 | 普通毛玻璃 | 红色底 rgba(255,69,58,0.04) |
| 图标 | 👋 | ⚠ |
| 确认文案 | "确认登出？登出后需重新登录" | "此操作不可撤销。所有下载记录、会员权益将被永久删除" |

### 26. Mockup 迭代策略

- **决策**: 每次迭代创建新文件，绝不覆盖旧版本
- **原因**: 保留完整设计演进轨迹，方便回溯和对比
- **结果**: 23 个 mockup HTML 文件，覆盖全部 5 个页面 + 交互流程
